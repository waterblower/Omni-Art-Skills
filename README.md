# Hermes All-in-One Creative Director

[中文文档](README.zh.md)

This is a production-oriented creative-skill library for Hermes Agent and Codex. It turns an agent into a combined producer, director, art director, asset manager, and visual QA reviewer—not merely a prompt writer.

The library is organized around a dependency-aware workflow: establish the source story, turn it into shot groups, build reusable assets and references, write executable image or video tasks, then review the output before it becomes a downstream reference.

## Skills

| name | description |
| --- | --- |
| [`creative-production-pipeline`](creative-production-pipeline/SKILL.md) | Manages the full creative-production workflow. |
| [`script-to-shot-table`](script-to-shot-table/SKILL.md) | Converts source material into production-ready shot groups. |
| [`manga-creation-pipeline`](manga-creation-pipeline/SKILL.md) | Develops comic stories into generation-ready pages. |
| [`video-prompt-director`](video-prompt-director/SKILL.md) | Creates executable prompts for AI video generation. |
| [`character-reference-pipeline`](character-reference-pipeline/SKILL.md) | Builds consistent, reusable character references. |
| [`image-art-direction`](image-art-direction/SKILL.md) | Reviews images for quality, style, and continuity. |
| [`image-generation-plan`](image-generation-plan/SKILL.md) | Creates asset-first TOML image-production plans. |
| [`image-quality-check`](image-quality-check/SKILL.md) | Checks generated images for defects and compliance. |
| [`style-distill`](.agents/skills/style-distill-v1.4/SKILL.md) | Extracts and validates reusable visual styles. |
| [`cover-image`](.agents/skills/cover-image/SKILL.md) | Creates Chinese video covers in strict ratios. |
