# Hermes 全能编导

[English](README.md)

这是一个面向 Hermes Agent 与 Codex 的生产型创作技能库。它让 Agent 同时承担制片、导演、美术指导、资产管理与视觉质检的职责，而不只是编写提示词。

整套技能按依赖关系组织：先确立故事源稿，再转化为镜头组，建立可复用资产与参考图，编写可执行的图片或视频任务，最后在产物进入下游参考链路前完成审核。

## 技能

| 名称 | 简介 |
| --- | --- |
| [`creative-production-pipeline`](creative-production-pipeline/SKILL.md) | 管理完整的创作生产流程。 |
| [`script-to-shot-table`](script-to-shot-table/SKILL.md) | 将源材料转化为可制作的镜头组。 |
| [`manga-creation-pipeline`](manga-creation-pipeline/SKILL.md) | 将漫画故事开发为可生成的页面。 |
| [`video-prompt-director`](video-prompt-director/SKILL.md) | 编写可执行的 AI 视频生成提示词。 |
| [`character-reference-pipeline`](character-reference-pipeline/SKILL.md) | 建立一致且可复用的角色参考。 |
| [`image-art-direction`](image-art-direction/SKILL.md) | 审核图片质量、风格与连续性。 |
| [`image-generation-plan`](image-generation-plan/SKILL.md) | 编写资产优先的 TOML 图片生产计划。 |
| [`image-quality-check`](image-quality-check/SKILL.md) | 检查生成图片的缺陷与任务符合度。 |
| [`style-distill`](.agents/skills/style-distill-v1.4/SKILL.md) | 提取\蒸馏美术风格。 |
| [`cover-image`](.agents/skills/cover-image/SKILL.md) | 按严格比例制作中文视频封面。 |
